# House_Price_Prediction
# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview

This project is a Machine Learning web application developed using **Python** and **Streamlit**. It predicts the estimated price of a house based on user inputs such as area, number of bedrooms, bathrooms, floors, parking spaces, house age, and location score.

The prediction model is built using **Linear Regression** from Scikit-learn and is deployed through an interactive Streamlit interface.

---

## 🚀 Features

- Predict house prices instantly
- User-friendly Streamlit interface
- Linear Regression Machine Learning model
- Interactive input fields
- Fast and accurate predictions
- Easy to use and deploy

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-link>
```

2. Install the required packages

```bash

```

3. Run the Streamlit application

